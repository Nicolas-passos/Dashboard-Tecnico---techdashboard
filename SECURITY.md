# Política de Segurança

## Dados sensíveis

Não publique em issues ou commits:

- Dados reais de chamados.
- Nomes de clientes.
- Usuários internos.
- Prints com informações confidenciais.
- Logos corporativas privadas, salvo quando autorizado.

## Upload de arquivos

A tela de branding aceita apenas imagens nos formatos:

- PNG
- JPG/JPEG
- SVG
- WEBP

## Relato de vulnerabilidade

Abra uma issue privada ou contate o mantenedor do projeto.
