# Configuração

## Filtros principais

- Ano.
- Quarter.
- Período personalizado.
- Usuários ocultos.

## Ocultar usuários

A função **Ocultar usuários** permite retirar contas de serviço, automações e usuários técnicos do cálculo das métricas.

Fluxo:

1. Clique em **Ocultar usuários**.
2. Pesquise ou marque usuários manualmente.
3. Use **Selecionar contas de serviço** para marcar usuários cujo título seja Conta de Serviço/Contas de Serviço.
4. Salve o filtro.

O filtro é aplicado a KPIs, gráficos e métricas.

## Layout personalizado

Use **Editar visão** para reorganizar quadros. O layout é salvo no navegador do usuário.
