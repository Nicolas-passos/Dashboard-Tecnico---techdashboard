# Exportação

O TechDashboard permite exportar os relatórios em:

- PDF, usando impressão do navegador.
- CSV compatível com Excel.

## Auditoria

Nas exportações são registrados:

- Usuário GLPI exportador.
- ID do usuário.
- Data e hora de geração.

O rodapé de auditoria fica oculto na tela normal e aparece apenas durante exportação/impressão.

## CSV

O arquivo CSV utiliza separador `;` e BOM UTF-8 para compatibilidade com Excel em português.

## PDF

Use o botão **Exportar → PDF** e escolha a impressora/salvamento em PDF do navegador.
