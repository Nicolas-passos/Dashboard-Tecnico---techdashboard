# Manual do Usuário

## Acessar o dashboard

No menu do GLPI:

```text
Ferramentas → Dashboard
```

## Atualizar filtros

1. Escolha o ano.
2. Escolha o quarter ou período personalizado.
3. Clique em **Atualizar**.

## Ocultar usuários

Use quando contas de serviço ou automações estiverem distorcendo métricas.

1. Clique em **Ocultar usuários**.
2. Marque os usuários que não devem entrar no relatório.
3. Clique em **Salvar filtro**.

## Exportar relatório

Clique em **Exportar** e escolha:

- PDF.
- Excel / CSV.

O relatório exportado contém rodapé de auditoria com usuário e horário.

## Reorganizar visão

1. Clique em **Editar visão**.
2. Use os controles de movimentação dos quadros.
3. Clique em **Salvar visão**.
